NLT API

Tyndale provides this API to the NLT for other web applications to use to include NLT text and search results on their own web pages.

Anonymous Access

You can begin using the NLT API anonymously right now, subject to the following limitations:

  • No more than 50 verses per request
  • No more than 500 requests per day
  • Non-commercial use (please sign up for commercial use license)
  • You affirm that your use is consistent with Tyndale’s purpose

Key-Based Use

If you want to exceed the limitations of anonymous use, you’ll need to request an API key using the sign up page. Our standard license terms for key-based use are:

  • No more than 500 verses per request (this matches the NLT copyright statement)
  • No more than 5000 requests per day
  • Non-commercial use (if your use is commercial, please explain when you sign up how you wish to use the API)
  • You affirm that your use is consistent with Tyndale’s purpose
