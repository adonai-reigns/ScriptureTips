# Translation and data sources: licenses and origins (Stage 2)

This document records, for each open or public domain text and data set ScriptureTips may distribute, **what the license actually says** and **where the files come from**. It follows the Stage 1 survey in [licenses.md](licenses.md).

## 1. How this was checked

- **Checked on 2026-10-25.** Everything below was read from the primary source on that date. License files, READMEs and file headers were read directly (downloaded and quoted), not taken from catalog summaries. Where only a secondary source was available, it says so.
- **Download links were tested.** Every eBible.org USFM archive named here returned HTTP 200 with a size and date (§3).
- **Two independent records were compared where possible:** the eBible.org catalog, the CrossWire SWORD module configs, and each project's own repository.
- **This is research, not legal advice.** Where a license is ambiguous, or a source contradicts itself, it's listed in §8 for a decision or a written question to the rights holder.

**License evidence is kept in [license-evidence/](license-evidence/):** one folder per translation, with the license pages as rendered PDFs, raw HTML, HTTP headers, the catalog entry, and the SHA-256 of the exact archive. Start with its `README.md`. **The files themselves** are kept outside git in `source-texts/`, identified by `license-evidence/source-files.json` and `SHA256SUMS`. The original-language data sets still need the same treatment.

## 3. English translations

**Origin for most of these: [eBible.org](https://ebible.org).** It's the distribution point run by Michael Paul Johnson (originator of the WEB). Each translation is published in many formats from one source. We'd ingest **USFM**.

- **Machine-readable catalog:** `https://ebible.org/Scriptures/translations.csv` (1,551 rows; 56 in English). It gives each translation's ID, title, `Redistributable` flag, copyright line, last-updated date, book and verse counts, and the CrossWire SWORD name. It's the index for an automated importer.
- **USFM archive:** `https://ebible.org/Scriptures/{id}_usfm.zip`. Each archive also contains `copr.htm`, the translation's copyright page, so the license notice travels with the text.
- **Not a license in itself.** The catalog's `Redistributable=True` is eBible.org's own statement. We should record it, but still review each translation before enabling it (§7).

**The WordPress plugin's `leb-bible-license.txt` is only a summary** ("Included for free with Adonai-Reigns.life"). It leaves out the trademark clause, the 50% rule and the FAQ. Use the full text above.

### 4.2 The NRSV family

The New Revised Standard Version comes in several editions, all © National Council of the Churches of Christ in the USA (NCC). They share one translation; they differ in spelling, in which deuterocanonical or apocryphal books they include, and in where those books sit. The 2021 revision (NRSVue) is a separate, updated text. **All of them follow the English (KJV-style) chapter and verse numbering** (Joel 3 chapters, Malachi 4). Sources: Bible Gateway version pages and Friendship Press's licensing page, captured in `license-evidence/nrsv-anglicised-catholic-edition/`.

## 6. Caveats inside the "open" data sets

These are the places where an open license on the package doesn't clearly cover everything inside it.

**STEPBible-Data**
- **Redistribution:** the README welcomes mirrors "so long as it is kept up-to-date and has a link back here". But every file header says "Please do not redistribute it yourself" and asks that it be distributed from one source. These need reconciling by asking STEPBible (§8). Our approach meanwhile: load the data from their repository into our database and link back, rather than re-publishing the files. TVTMS is obtained this way (`license-evidence/stepbible-data/`).
- **`TBESH` Hebrew brief lexicon:** "based on Abridged BDB by Online Bible … **Permission should be gained from Online Bible before these definitions are applied in any project.**" That conflicts with the CC BY label. Don't use the `TBESH` definitions until resolved; use `HebrewLexicon` BDB (public domain text) instead.
- **`TBESG`/`TFLSJ` (Greek):** built on Abbott-Smith (public domain) and the Liddell-Scott-Jones lexicon "from Perseus", plus some entries from Mounce's Teknia dictionary "with permission". Perseus's own license for LSJ and the scope of Mounce's permission weren't checked.
- **`TAGNT` (Greek NT):** the spelling follows **NA28** and the word list covers NA27/28 (copyrighted editions). Its English comes from the Berean Study Bible "with permission" (the BSB is now public domain). Its Spanish text and context-sensitive sub-meanings come from the **Marvel Bible Project / OpenGNT**, whose terms we haven't cleared. Use the SBLGNT, Byzantine and Textus Receptus columns, and leave out the Spanish and sub-meaning fields until cleared.
- **`TAHOT` (Hebrew OT):** "derived from … WLC 4.20 via OpenScriptures, checked against the Stuttgartensia electronic text … essentially, a corrected version of BHS". BHS is a copyrighted edition; Tyndale House licenses its data as CC BY, but confirm that covers the text.
- **`TIPNR` (proper names):** the brief, short and article descriptions were "adapted from the output by Claude 3 Opus AI in April 2024". The file's license allows sending the data to AI servers. Disclose that these descriptions are AI-generated.

**MACULA**

The full exclusion list, with file paths and the commits it was checked against, is in [`license-evidence/macula/SOURCE.md`](license-evidence/macula/SOURCE.md). In short:
- **Hebrew:** leave out the **Semantic Dictionary of Biblical Hebrew** (© UBS, "Used with permission": columns and attributes `sdbh`, `lexdomain`, `coredomain`, `contextualdomain`), and the **SIL Hebrew-English glosses** in the `gloss` column (© SIL International, a free-to-share license that isn't an open one). Use the Cherith gloss (`english`) instead. Also leave out `sources/MARBLE/` and the MARBLE mapping files.
- **Greek:** leave out the UBS **MARBLE** word senses, the Louw-Nida domains ("Used with permission": `ln`, `domain`), and `sources/MARBLE/`.
- **Not needed:** the unfoldingWord figures-of-speech files (`sources/door43/`, CC BY-SA 4.0).
- **Fine to use:** the syntax trees (Groves Center, CC BY 4.0), OSHB morphology (CC BY 4.0), Cherith glosses (CC BY 4.0), the SBLGNT edition (CC BY 4.0), Nestle 1904 word data (text public domain, morphology CC0; not the CC BY-SA biblicalhumanities markup), and Clear's own annotations.
- The Greek `gloss` column is the Berean Interlinear (public domain since the 2023 dedication).

**eBible.org texts**
- The USFM files carry **Strong's numbers** on English words. Who produced those tags isn't stated on the copyright pages. For public domain texts, eBible publishes them as part of the public domain text; for the LSV and FBV they fall under the CC BY-SA license. Treat them as part of each text, and don't treat them as an independent Strong's data set.
- The copyright pages don't say where each older text was digitized from (ASV, YLT, Darby, etc.). CrossWire's configs give a few sources (Darby: bibliquest.net; Webster: bf.org; BBE: Unbound Bible).

## 7. Proposed ingestion approach

1. **A source ledger.** Each imported file gets a `SourceRecord`: origin URL, retrieval date, SHA-256 of the archive, the license text as it was on that date (e.g. `copr.htm`, `LICENSE.md`), and the catalog's own claim. This provides the evidence trail if a license changes, and ties into the published-history rules.
2. **The importer reads the eBible catalog** (`translations.csv`) on a schedule, compares `UpdateDate`, and fetches new USFM archives. It never enables a translation automatically: a person reviews the license first, and the review result is stored.
3. **Per-translation license records** feed the license engine (licenses.md §8): rule types such as `share_alike` (LSV, FBV, ULT, UST, MorphGNT, First1KGreek), `attribution` (STEPBible, OSHB, SBLGNT, MACULA), `name_restriction` (WEB, BSB, unfoldingWord), `jurisdiction_exception` (KJV in the UK) and `no_modification` where it applies.
4. **Credits are generated from the ledger,** so printed editions and the website show the exact attribution each license requires.
5. **Pin versions.** Import a specific release or commit, not "latest", so a license change upstream can't silently affect what we serve.
6. **Prefer upstream sources** (e.g. Door43, OSHB, SBLGNT) over aggregators and re-packagers, which can carry stale or mixed licenses.
7. **Scripture cache with priming sources.** The API serves scripture only from its cache, stored per verse. Each translation has a priming source configuration (an imported file, our own database, or a publisher's API) used only when a verse is missing or its entry has expired. Each entry records the source and the date fetched, plus two expiries: `storage_expires_at` (a license limit on holding the content; the verse isn't served until it's fetched again) and `refresh_after` (when to check for updates; stale content may be served if the refresh fails). Fetched content that differs from the cached copy is logged and raises a notice, because it may be a new upstream edition whose license terms need checking again. See [domain-model.md](domain-model.md) §2.5.
