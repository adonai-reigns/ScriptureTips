## License as stated by the rights holder

The prologue of `strongsgreek.xml` (the dictionary taken from James Strong's *Exhaustive Concordance*, 1890):

> "Dictionary of Greek Words taken from Strong's Exhaustive Concordance by James Strong, S.T.D., LL.D. 1890 **Public Domain -- Copy Freely**"

> "The XML version of this work was prepared in 2006 by Ulrik Petersen (http://ulrikp.org) from the ASCII e-text version presented below. The XML version contains "real" UTF-8 Greek where the original ASCII e-text version had transliteration."

The ASCII e-text it came from was produced by Michael Grier in 1996. The repository itself has no separate license file; the prologue is the statement.

**What this means for us:**
- We may use the entries (Strong's numbers, Greek words, transliterations, derivations and definitions) freely, with no attribution required. We credit "Strong's Exhaustive Concordance (1890), XML version by Ulrik Petersen, via the Open Scriptures project" as a courtesy.
