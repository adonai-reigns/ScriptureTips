# License evidence

A record of the license and distribution terms for every text ScriptureTips obtains, kept **at the time of obtaining it**. Licenses change, websites move (the LEB's original host no longer exists), and rights holders change. If a question ever arises, these folders show what the terms were, where the file came from, and exactly which file we took.

## Captured in a person's browser

Some sites refuse automated access (HTTP 403/503). Their pages were printed to PDF in Firefox and are labeled as such in each `SOURCE.md`:
- Cambridge University Press "Bibles rights and permissions" (in `king-james-version/`). The old *Queen's Printer's Patent* URL now redirects to a page with no rights information.
- bible.org copyright and NET download pages (in `net-bible/`).
- tyndale.com permissions and purpose pages (in `new-living-translation/`, `the-living-bible/` and `the-message/`), captured in the project owner's Chromium through its remote debugging connection, so their HTML is the rendered page and there are no HTTP headers.

## What to capture whenever a text is obtained

1. **The license page(s)** as rendered, saved as PDF with the date and URL visible (headless browser or Print to PDF), plus the raw HTML and the HTTP response headers.
2. **The download page** that offers the file, so the origin and formats are on record.
3. **The license files inside the download** (e.g. `copr.htm`, `LICENSE.md`, license text embedded in the data).
4. **The file itself identified exactly:** URL, size, last-modified date and **SHA-256**. Save the file in `source-texts/` and add it to `source-files.json` and `SHA256SUMS` (see "Source files" below).
5. **Any machine-readable record** the source offers (catalog entry, module config).
6. **A `SOURCE.md`** with the license quoted, the conditions, and caveats.
7. **Look at every captured page.** Some sites lose their stylesheet under print rendering (Door43/Gitea did) or hide content until scripts run (lsvbible.com did). If a PDF looks wrong, take a screen-mode capture instead. The pages captured that way are noted in each `SOURCE.md`.
8. **Never overwrite a capture.** If the terms or the file change, add a new dated capture alongside the old one.

## Source files

The texts themselves are kept **outside git**, in `source-texts/` next to the repositories (`/home/antz/Projects/GitHub/adonai-reigns/source-texts/`), with one folder per evidence folder here. They'll move to cloud storage later. Two files in this folder identify each one exactly:

- `source-files.json`: for every file, its path, origin URL, size, SHA-256, retrieval date, the evidence record it belongs to, and whether it matched that record.
- `SHA256SUMS`: the same hashes in the standard format, so any copy can be checked with:
  `cd source-texts && sha256sum -c /path/to/ScriptureTips/docs/license-evidence/SHA256SUMS`

Retrieved 2026-10-25: 33 files, about 123 MB. All 28 eBible.org and Door43 archives matched the hashes recorded in their evidence folders. The Open English Bible GitHub archive (commit `1965127d`) had no earlier hash, so its hash was first recorded here. The three LEB files are the original 2020 downloads, taken from `tex-bible` commit `2ef97e4`.

Retrieved 2026-10-26: 11 more files for JPS 1917, about 1 GB: the Internet Archive scan `jps1917` (10 files, each matched archive.org's published SHA-1) and Open Siddur's `Tanakh1917.txt` from the Wayback Machine (first recorded here). 44 files in total.

Retrieved 2026-10-26 (later): 6 Berean files, about 41 MB: the Berean Literal Bible (`blb.txt`, `.xlsx`, `.pdf`, `.docx`) and the Berean Interlinear Bible (`bib.pdf`, `.docx`), first recorded here. 50 files in total.

Retrieved 2026-10-26 (TVTMS): 2 files from STEPBible-Data at commit `be4191f`, about 5.8 MB: the TVTMS versification file and the repository README, first recorded here. 52 files in total.

**If a re-download doesn't match:** the source has changed. Keep the old file, save the new one under a dated name, and capture the license again (checklist item 8).
